# Raspberry-Pi-based-Bluetooth-RC-car



A Raspberry Pi-based Bluetooth-controlled robotic car using Python and an L298N motor driver.

## Features

- Bluetooth control
- Forward, backward, left, right
- Stop command
- Python 3
- Raspberry Pi GPIO

## Hardware

- Raspberry Pi 4
- L298N Motor Driver
- DC Motors
- Bluetooth Module (HC-05 or built-in Bluetooth)

## Run

```bash
python3 bluetooth_rc_car.py
```
